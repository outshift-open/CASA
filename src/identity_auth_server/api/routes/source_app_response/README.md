# Source App Response API Routes

This package exposes REST endpoints for persisting responses generated by source applications. Routes are registered via FastAPI and backed by the Postgres implementation of `SourceAppResponseRepository`.

## POST `/source-app-response`

Create a new source app response record linked to an existing source app call.

- **Request Body** — `SourceAppResponseInput`
  - `token` (`string`): Unique token associated with the response.
  - `source_app_call_token` (`string`): Token of the previously stored source app call.
  - `output` (`string`): Raw payload returned to the source application.
- **Response Body** — `SourceAppResponse`
  - `id` (`UUID`): Generated identifier for the stored response.
  - `source_app_call_id` (`UUID`): Identifier of the associated source app call.
  - `token` (`string`): Echo of the request token value.
  - `output` (`string`): Echo of the response payload.
  - `created_at` (`string`, ISO 8601 timestamp): Creation time in UTC supplied by the persistence layer.

### Example

```bash
curl -X POST \
  http://localhost:8000/source-app-response \
  -H 'Content-Type: application/json' \
  -d '{
    "token": "sample-response-token-123",
    "source_app_call_token": "sample-call-token-123",
    "output": "{\"status\": \"ok\"}"
  }'
```

**Sample response**

```json
{
  "id": "c9b541f6-7cfd-4465-9e37-4fb41adfb30a",
  "source_app_call_id": "0d9f1a63-b3aa-4c3c-86b5-4e25a9fb42de",
  "output": "{\"status\": \"ok\"}",
  "created_at": "2025-01-09T12:32:00.123456Z"
}
```

> ℹ️ The router does not attach a prefix by default. When mounted under a larger FastAPI application, the final path may include an additional prefix depending on how it is included.
